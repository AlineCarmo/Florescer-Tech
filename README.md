# Florescer Tech
Projeto da ONG Florescer Tech desenvolvido durante a faculdade.

## Sobre o projeto

A Florescer Tech é uma proposta de ONG voltada para a inclusão e capacitação digital. O projeto foi desenvolvido com o objetivo de apresentar iniciativas relacionadas à tecnologia, educação e oportunidades, além de permitir que pessoas interessadas possam realizar um cadastro para participar.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Funcionalidades

- Navegação entre as seções do site.
- Menu responsivo para dispositivos menores.
- Seção de projetos e áreas de atuação.
- Modal com informações adicionais.
- Formulário de cadastro com validação.
- Armazenamento de dados no localStorage.
- Mensagens de interação com o usuário.
- Recursos de acessibilidade, como navegação semântica, textos alternativos e controle do estado do menu.

## Acessibilidade

Durante o desenvolvimento, foram aplicadas práticas relacionadas à acessibilidade, como:

- utilização de HTML semântico;
- textos alternativos nas imagens;
- utilização de label nos campos do formulário;
- uso de fieldset e legend;
- indicação de foco nos elementos interativos;
- atributo aria-label no botão do menu;
- atributo aria-expanded para indicar o estado do menu.

## Versionamento

O projeto utiliza Git e GitHub para controle de versão.

Foi utilizada uma estrutura de branches baseada no GitFlow:

main: versão estável do projeto;
develop: desenvolvimento da aplicação;
feature/acessibilidade: desenvolvimento da funcionalidade de acessibilidade.

## Como executar

Para executar o projeto localmente, faça o download ou clone este repositório e abra o arquivo:

html/index.html

O projeto utiliza HTML, CSS e JavaScript, não sendo necessário instalar dependências externas para executá-lo.
